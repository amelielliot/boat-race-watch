# Boat Race Watch

全国24場を5分ごとに確認し、締切約10分前のレースについて、買い候補または見送り理由を iPhone の ntfy に通知する個人用ツールです。舟券を自動購入する機能はありません。

## 初期設定

1. iPhone に **ntfy** をインストールする。
2. 推測されにくいトピック名を作成して購読する（例ではなく、長いランダム文字列を使う）。
3. GitHub リポジトリの `Settings > Secrets and variables > Actions` に `NTFY_TOPIC` を登録する。
4. `Actions > Boat Race Watch > Run workflow` でテストする。

## 判定仕様

- 対象：全国24場、締切7〜13分前
- 上限：1レース2,000円、1日5,000円
- 安全見送り：直前情報欠損、進入不明、1号艇のイン外れ、風速6m以上、波高10cm以上、オッズ取得失敗
- 推定：選手全国・当地成績、モーター2連対率、平均ST、展示ST、展示タイム、進入コースを合成
- 買い候補：1号艇1着の3連単のみ、推定期待値1.15以上、最大3点

## 重要

初期状態は `SHADOW_MODE=true` です。通知には金額が表示されますが、検証中は買いません。最低でも2〜4週間、的中率だけでなく回収率と最大連敗を確認し、基準を再調整してから実運用を判断してください。

本ツールの確率は統計モデルではなく初期ヒューリスティックです。利益を保証しません。欠場・進入・締切・最新オッズは必ず BOAT RACE 公式画面で確認してください。20歳未満は舟券を購入できません。

## データ

- 出走表・直前情報：Boatrace Open API（非公式、約3分間隔）
- 直前3連単オッズ：BOAT RACE オフィシャルウェブサイト（締切対象レースのみ低頻度取得）
- 通知：ntfy HTTP API
